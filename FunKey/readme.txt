Unreal - FunKey S / Anbernic RG Nano
====================================

Game data goes in /mnt/FunKey/Unreal/ with the System/, Maps/, Textures/,
Sounds/ and Music/ folders from a retail Unreal v200 install or the v205
demo. Logs are written to /mnt/FunKey/Unreal/funkey.log.

Controls (hold L shoulder for the Fn layer)
-------------------------------------------
  D-pad Up/Down     Move forward / backward   (Fn: look up / down)
  D-pad Left/Right  Turn left / right         (Fn: prev / next inventory)
  A                 Fire
  B                 Alt-fire
  X                 Jump                      (Fn: duck)
  Y                 Next weapon
  R shoulder        Activate inventory
  Start             Enter / confirm
  Select            Center view
  Power / Menu      Menu (Escape)
  L shoulder        Fn modifier (hold)

All bindings can be changed in-game under Preferences.

New players: go to Options and turn on auto aim and view spring, and
remap the buttons if these defaults don't suit you.
